
# AeroLink Nepal

## Airport Communication & Surveillance Network Simulator

### Project Overview
AeroLink Nepal is a Python-based educational simulator
for understanding digital communication, wireless channels,
aircraft surveillance, and network reliability.

### Project Objectives
1. Simulate BPSK and QPSK modulation.
2. Analyze the effects of noise and SNR on BER.
3. Measure or simulate network latency, jitter, and packet loss.
4. Compare wireless path loss at 800 MHz and 1800 MHz.
5. Generate and visualize simulated aircraft data.
6. Demonstrate network redundancy and failover.

### Technologies
Python, NumPy, Pandas, Matplotlib, Plotly, Streamlit.

### Current Progress
Day 1: Python environment and initial dashboard completed.

### How to Run
Install dependencies:
python -m pip install -r requirements.txt

Launch:
python -m streamlit run app.py

Open http://localhost:8501 in your browser.

### Disclaimer
Educational simulation only.
Not intended for real airport or aviation operations.
